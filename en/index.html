From upload to report in three steps.

  1. Upload

    Upload your personnel file in Excel, CSV or ODS format. Column names don’t need to match the product template exactly.

  2. Mapping

    Unrecognized columns are mapped once. The mapping is saved and applied automatically to every later upload.

  3. Reporting

    Indicators, alerts and an action list are generated. Missing data is never estimated; the field shows “Insufficient data” instead.

Data integrity. No unreadable value is silently dropped; each one is listed in the upload report. Data is saved in a single transaction, so if anything fails, your existing data stays exactly as it was.

A security model built for sensitive personnel data.

Salary, garnishment and identity details are some of the most sensitive data an organization holds. That is why security is part of the product’s foundation, not a setting added later.

Two-factor authentication
Mandatory on the Enterprise plan; a password alone is never enough to sign in.
Role-based access
Owner, HR Specialist, Payroll, Training and Summary roles are defined. Salary and garnishment details are shown to authorized roles only.
Audit log
Records which user viewed or changed which data, and when. If the log can’t be written, access to the data is not granted.
Encrypted sensitive fields
Turkish ID number, phone, email, special status and reason for leaving are stored encrypted with AES-256.
Isolation between organizations
The database enforces row-level access control, so each organization can reach only its own data.
Session management
Inactive sessions close automatically (after 30 minutes on the Enterprise plan). Users can see their open sessions and end them.
Data location
Data is stored within the European Union, in a data center in Ireland.

Frequently asked questions

Which file formats are supported?

Excel (.xlsx, .xls), CSV and ODS. Column names can differ from the product template; unrecognized columns are linked once on the mapping screen and remembered for later uploads.

If an upload fails, is our data affected?

No. Data is saved in a single transaction, so if an error occurs, your organization’s existing data stays unchanged. Unreadable or invalid values are never silently dropped; they are listed in the upload report.

Where is the data stored, and can other organizations access it?

Data is stored in the European Union, in a data center in Ireland. The database enforces row-level access control, so each organization can access only its own records.

Which users can see which data?

There are five roles: Owner, HR Specialist, Payroll, Training and Summary. Sensitive data such as salary and garnishments is shown to authorized roles only. Every view and change is written to the audit log.

What is shown when data is missing?

The screen shows “Insufficient data”. Missing values are not estimated or counted as zero, and any records left out are noted on screen.

Is the severance pay figure final?

No. The severance liability (kıdem tazminatı) on the Pay and Budget screen is a potential upper limit, calculated against the ceiling you enter; the actual payment depends on the reason for leaving. For an exact figure, please consult your financial advisor.
